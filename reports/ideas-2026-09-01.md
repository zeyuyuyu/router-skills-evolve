## Top 3 Relevant Papers

### 1. arxiv:2602.00166 — DA-GRPO: Joint Continual Learning + Cloud Offloading
**Submitted:** February 2026

**Core claim:** DA-GRPO extends GRPO with a dual-advantage objective that encodes
cloud-usage constraints directly into the policy gradient. The local small model learns
task competence and cloud-offloading decisions jointly — no external routing model, no
fixed reward shaping. On math reasoning and code generation, DA-GRPO reduces forgetting
and maintains cloud-usage within budget across continual task streams.

**Key design axes vs. MERA:**

| Axis | DA-GRPO | MERA |
|---|---|---|
| Routing signal | Dual advantage inside GRPO | Separate supervised router on oracle labels |
| Procedure / skill prefix | None | SkillBook procedure prefix (CLAUDE.md #4) |
| Iterative cycles | Single post-training pass | N co-evolution cycles (checkpoint #6) |
| Budget constraint | Explicit cloud-call fraction | Unconstrained, learns from pass-rate |

**Relevance to MERA:** DA-GRPO is the closest published near-neighbour to MERA's
architecture. An ICLR 2027 reviewer familiar with it would challenge §2 novelty. EXP-204
(queued today) drafts the §2 differentiation paragraph mapping these four axes.

### 2. arxiv:2605.28791 — Skill-Conditioned Gated Self-Distillation for LLM Reasoning
**Submitted:** May 2026

**Core claim:** A skill classifier identifies per-sample skill gaps between student and
teacher; a gating mechanism activates teacher distillation only for tokens corresponding
to those skill gaps. This avoids over-distilling on skills the student already has, and
under-distilling on genuine skill gaps. Outperforms uniform self-distillation on
multi-step reasoning and code tasks.

**Relevance to MERA:** MERA's SkillBook prepends the same global "coding" procedure to
every prompt (CLAUDE.md Decision #1). This is simpler than skill-gated distillation but
potentially weaker. The key question is whether MERA's `can_downgrade_to_small` verdict
(now diagnostic) already implements an implicit coarse skill gate — and whether real
per-skill gating would require breaking the router-owns-routing design (CLAUDE.md
Decision #2). EXP-205 (queued today) audits this and drafts the §3 footnote.

### 3. arxiv:2607.20481 — Routing Without Training: Controllable-Ratio LLM Offloading via Reliability Gating
**Submitted:** July 2026

**Core claim:** A zero-training router assigns each query to local or cloud based on a
reliability gate (confidence score on a calibration split), with a tunable offload-ratio
parameter. No gradient required; the router is deployable immediately on a new model pair.
Accuracy–cost tradeoffs on RouterBench competitive with learned routers at low-data regimes.

**Relevance to MERA:** MERA's learned router (train_router_simple.py) requires N cycles
of oracle labels to reach its reported routing accuracy. arxiv:2607.20481 is the strongest
zero-training baseline to cite as a §4 ablation contrast. A future EXP-20x could
implement the reliability-gating router as a zero-training baseline in MERA's four-arm
ablation — but this is a GPU experiment requiring A800 access. Flagged for future slot.
