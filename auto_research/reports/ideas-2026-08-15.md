### 1. arxiv:2608.04788 — "Agentic Reinforcement Learning with Observation-Calibrated Self-Distillation (OCSD)"

**Relevance: ★★★ — SECOND CONCURRENT AGENTIC RL PAPER — EXTENDS §2 ADRS CLUSTER**

**Key finding** (August 5, 2026): OCSD addresses the fundamental confound in On-Policy Self-Distillation (OPSD): dense token-level supervision from a "privileged replay view" (one that includes future environment observations) conflates two signals — genuine policy improvement and artefacts induced by the privileged context. To disentangle them, OCSD computes the "observation-calibrated gap" by contrasting a Full replay view (with future observations) against an Observation-Ablated view (identical structure, but future observations removed). The difference is a cleaner credit signal for which tokens were genuinely improved vs. which were steered by privileged information. OCSD outperforms OPSD on multi-turn web agents (WebArena, ALFWorld) and transfers better to held-out environments.

**MERA vs. OCSD vs. ADRS — three-way comparison:**

| Dimension | MERA | ADRS (2608.03223) | OCSD (2608.04788) |
|---|---|---|---|
| Privileged signal type | SkillBook procedure (GPT-5.5 distilled) | Procedural skills (TVA gate) | Future environment observations |
| Inference-time conditioning | **Yes (cycle 0 only; collapses cycle 1+)** | No | No |
| Credit mechanism | Sequence-level GRPO binary reward | Token-level TVA gate | Token-level observation-calibrated gap |
| Routing component | **Yes (logistic regression, Phase 4)** | No | No |
| Task horizon | Single-turn code generation | Multi-turn interactive agents | Multi-turn web agents |
| Co-evolution across cycles | **Yes (LLM + SkillBook + Router)** | No | No |
| Submitted | — | 2026-08-04 | 2026-08-05 |

**Key insight for §2**: ADRS and OCSD converge on the same design principle — privileged signals are useful at training time, but should not appear at inference to avoid distribution shift and deployment-phase dependence. MERA's SkillBook collapse (EXP-163) empirically arrives at the same outcome: from cycle 1, the inference-time procedure is de facto empty (17–21 word noise sequences), so MERA converges to the ADRS/OCSD principle in practice. Stating this in §2 preempts the reviewer question "doesn't inference-time conditioning hurt MERA?" with the answer: "No — the procedure collapses after cycle 0, so inference-time conditioning becomes negligible; see EXP-163."

**§2 cluster paragraph additions** (extending EXP-164's ADRS paragraph):
```
ADRS (arxiv:2608.03223, concurrent) and OCSD (arxiv:2608.04788, concurrent) independently
validate that privileged training signals — procedural skills (ADRS) and future environment
```
