## Top 3 Relevant Papers

### 1. Self-Evolving Coding Agents — arxiv:2608.03392 (August 2026)
**Relevance: CRITICAL — maps directly onto MERA's full architecture for §2**

Structured taxonomy of coding agents that continuously update themselves from repository interactions. Five axes: memory, skills, tools, model weights, collaboration structure. Distinguishes how evolution is triggered (feedback, reflection, reward), stored, and applied.

MERA evolves three axes simultaneously: skills (SkillBook), weights (SFT→GRPO), collaboration (router). The other two axes (tool set, per-task episodic memory) are fixed in MERA and become concrete future-work bullets. The survey also distinguishes static post-deployment agents from continual ones — MERA is the latter, making this the highest-coherence §2 anchor of the week.

Companion: **CODESKILL (arxiv:2605.25430)** — reformulates skill management as an RL-trained policy using dense rubric + sparse execution reward. Closest external analog to MERA's SkillBook distillation; differentiator is that MERA uses a fixed GPT-5.5 distiller (no distiller-RL training stage).

### 2. G²RPO-A: Adaptive Guided GRPO — arxiv:2508.13023 (August 2025)
**Relevance: HIGH — directly addresses GRPO zero-reward failure on small models**

Injects ground-truth reasoning steps as "guidance" during GRPO rollout generation. Uses a learned adaptive controller to anneal guidance strength as training progresses. Addresses the core failure mode where small models produce zero correct rollouts → zero advantage → no gradient.

In MERA: the SkillBook procedure is a static prefix during GRPO rollout. G²RPO-A suggests making it adaptive: stronger procedure scaffold for hard problems (pass@1 < 0.5 in cycle N), standard prefix for easy ones. Guidance is annealed over cycles 4→6. Distinct from the 2026-08-19 replay/curriculum experiments (changes prompt content, not batch order).

### 3. GeRe: General Samples Replay — arxiv:2508.04676 (August 2025)
**Relevance: MEDIUM — principled continual-SFT anti-forgetting strategy**

Replays a small sample of general pretraining text alongside domain SFT batches, combined with a threshold-based margin loss for activation consistency. Prevents capability collapse during sequential fine-tuning with minimal storage.

In MERA: `SFT_INCLUDE_SUCCESS=1` is the current collapse prevention heuristic (~77 pairs vs ~19). GeRe offers a principled complement: add a 10% fraction of diverse Python pretraining snippets to each SFT batch to maintain general code fluency between cycles. Less targeted than cycle-specific replay but more robust to data sparsity.

### EXP-175 — G²RPO-A Adaptive Guided GRPO with Procedure Annealing
**ID:** `exp_2026_08_20_002_grpo_adaptive_guided_procedure_annealing_g2rpo_a`  
**Kind:** `grpo_continual`  
**Priority:** 7  
**GPU:** Required (~3.5h on A800, DAPO + LoRA)  
**Paper:** arxiv:2508.13023

**Rationale:** Vanilla GRPO on small models fails when zero rollouts are correct (zero advantage → no gradient). G²RPO-A (2508.13023) injects ground-truth guidance into rollouts and adaptively anneals it. MERA's procedure prefix is already in every GRPO rollout but is static. This experiment adapts G²RPO-A's principle: for HumanEval problems where cycle-3 pass@1 < 0.5 ("hard"), inject a stronger scaffold (procedure prefix repeated ×2 + first worked-step from a successful trace); for easy problems (pass@1 ≥ 0.5), use the standard prefix. Guidance is annealed across 3 cycles (cycles 4→6). Algorithm: DAPO (non-symmetric clip, better for hard problems). This is distinct from the 2026-08-19 experiments: replay (reuses old traces), hard-first curriculum (reorders batches), staircase seeds (threshold variation). This experiment changes the *content* of the prompt for hard problems only.

**Spec:**
- From checkpoint: `results/e2e_4cyc_gpt55/cycle_3/grpo_adapter`
- Bench: humaneval, n_cycles=3, GRPO temp=0.9, batch=1, K=8, algo=dapo
- Hard split: cycle-3 pass@1 < 0.5 → double-prefix scaffold with first 2 worked steps
- Cycle 5: hard scaffold reduced to 1.5× (single prefix + first 2 steps only)
- Cycle 6: standard prefix for all (full annealing)
- Compare against: exp_2026_08_19_001 (replay), exp_2026_08_19_002 (hard_first)
