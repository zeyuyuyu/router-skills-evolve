## Top 3 Relevant Papers

### 1. Agentic Reinforcement Learning with Self-Distilled Reward Shaping
**arxiv:2608.03223** | August 2026

Self-distilled reward shaping that uses the gap between teacher and student performance
as an implicit reward signal for GRPO. Directly relevant to MERA's 20.7% teacher-pass /
student-fail population — that population is precisely where self-distilled reward
shaping would focus. Connects to planned EXP-120 (Dr.GRPO variant) and the §2c RL
section for ICLR 2027.

### 2. SynConfRoute: Syntax-Aware Routing for Efficient Code Completion with Small CodeLLMs
**arxiv:2605.04894** | May 2026

Uses AST-level syntax confidence signals to route code completions between small and
large models. MERA's TF-IDF router is query-surface only; SynConfRoute's syntax-aware
signal is complementary. Useful §2 LLM Routing citation for ICLR 2027 — situates MERA
as a *learned* (query-surface, training-data-driven) router vs. *rule-based* (syntax-
confidence) approaches. MERA's 93.04% routing accuracy is competitive against their
reported baselines.

### 3. SIRI: Self-Internalizing Reinforcement Learning with Intrinsic Skills for LLM Agent Training
**arxiv:2606.02355** | June 2026

Intrinsic skill reward shaping where the agent learns to recognize and reuse skill
primitives without external supervision. Parallels MERA's SkillBook procedure distillation
but from an RL (not SFT) perspective. Key distinction: MERA externalizes skills as a
prompt prefix (interpretable, transferable); SIRI internalizes them as latent reward
weights. Useful ICLR 2027 §2 positioning: MERA = explicit + modular vs. SIRI = implicit
+ end-to-end.
