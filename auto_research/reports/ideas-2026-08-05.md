## Top 3 Relevant Papers Found Today

### 1. arxiv:2607.19313 — "Off-Context GRPO: Learning to Reason on Hard Problems using Privileged Information"

**Relevance: ★★★ — NEW THIRD DARK ROOM FIX**

**Key finding** (Jul 21 2026): When every rollout on a hard prompt fails (our all_fail dark room
tasks), RLVR reaches a "learning cliff" — zero variance, zero gradient, zero progress. OC-GRPO
breaks this by injecting privileged information (solution prefixes) into the rollout sampling
prompt, steering the model toward at least some correct rollouts. An importance-weighted
GRPO update then targets the original unguided distribution, preventing the prefix from
becoming a training-time crutch. Result: 3.9% absolute improvement (13.8% relative) over
vanilla GRPO on competitive math tasks.

**Direct application**: Our 10-13 all_fail tasks per cycle each have a `expected` reference
solution. Using the first 3 lines as a privileged prefix during GRPO rollout sampling would
break the learning cliff for these tasks. The importance correction ensures the model learns
from these guided samples without memorizing the prefix pattern. This is:
- Orthogonal to EXP-135 (no-std-norm): that fix patches the normalization layer; OC-GRPO
  fixes the sampling layer
- Orthogonal to EXP-147 (DHRCL 3-tier): that fix changes the reward signal; OC-GRPO changes
  which rollouts are generated

All three can in principle be combined. For AAAI: a 3-approach comparison in §5.4 ("Dark Room
Remedies") citing all three arxiv papers (2607.21273, 2607.26457, 2607.19313) positions our
work squarely in the center of the current dark room research wave.

**Distinction from EXP-135/147**: No reward engineering, no normalization change. Pure sampling
modification. Most closely aligns with curriculum-based approaches (task difficulty bootstrap).

### 2. arxiv:2607.21273 — "The Dark Room in the Reward Channel: Dense Prediction Rewards Collapse GRPO-Trained LLM Agents — and What Actually Works"

**Relevance: ★★★ — DIRECTLY VALIDATES EXP-135 AND NAMES OUR PATHOLOGY**

**Key finding** (Jul 23 2026, Yu Wang, under review): Under group-normalized GRPO, prediction
rewards for agentic tasks drive training into a degenerate "dark room" absorbing state — the
optimizer finds it trivially easy to predict its own state, achieving prediction accuracy → 1.0
while task success → 0. The root cause (Proposition 1): when all K rollouts receive identical
reward (all-pass or all-fail), GRPO's std normalization produces 0/0 advantages, implemented
as 0, producing zero gradient. Removing std normalization (a single-line change) turns the
catastrophic reward from 0% → baseline parity across Qwen3-1.7B/4B/8B on ALFWorld.

**Direct application**: This paper provides the formal theorem backing EXP-135's hypothesis.
Proposition 1 is exactly what we've been observing: 47-52% of GRPO steps are dark room steps
across 4 cycles. The paper's "what actually works" section (std-norm removal) maps to EXP-135.

**Paper impact** (two uses):

   GRPO's std normalization silently zeroes gradients on all-fail groups, naming this the
   'dark room pathology' and identifying std-norm removal as the root-cause fix. Our EXP-135
   independently targets the same mechanism in a code generation continual-training pipeline."

### 3. arxiv:2509.21880 — "No Prompt Left Behind: Exploiting Zero-Variance Prompts in LLM Reinforcement Learning via Entropy-Guided Advantage Shaping"

**Relevance: ★★ — EARLIER TREATMENT, COMPLEMENTARY MECHANISM**

**Key finding** (Sep 2025, RL-ZVP): Zero-variance prompts (all-pass or all-fail under binary
rewards) are not useless — they carry directional information about policy confidence. RL-ZVP
uses entropy to shape advantages on these prompts: reward correct all-pass rollouts with a
bonus proportional to policy entropy (punish overconfidence on easy tasks) and penalize
all-fail rollouts with an entropy-weighted negative signal (push away from uniformly bad
behaviors). This recovers gradient on zero-variance prompts without privileged prefixes or
reward re-engineering.

**Distinction from EXP-135/147/148**: Entropy-based shaping is a pure policy-side intervention;
no reference solutions, no reward tiers, no importance weights. Theoretically applicable to
both all-pass (entropy bonus prevents trivial exploitation) and all-fail (entropy penalty
pushes away from the current bad policy region).

**Action**: Not queued today (at 2-experiment cap). Record for §2 Related Work: "RL-ZVP
(arXiv:2509.21880) recovers gradient on zero-variance groups via entropy-shaped advantages,
without requiring privileged information (OC-GRPO, arXiv:2607.19313) or reward re-engineering
(DHRCL, arXiv:2607.26457). Our EXP-135 (std-norm removal) is the simplest intervention, most
directly motivated by arxiv:2607.21273's Proposition 1."

**Rationale**: arxiv:2607.21273 Proposition 1 formally proves that GRPO's std normalization
produces zero gradient on all-fail groups. EXP-149 uses this framework to compute the
**effective gradient utilization rate** for each of our 4 cycles: what fraction of the 125
GRPO steps per cycle contributed non-zero gradient? The oracle upper bound is: if all dark
room waste were eliminated (by EXP-135 + EXP-147 or any combination), effective steps per
cycle would rise from ~48-54% to 100% — roughly doubling the learning signal. This converts
the abstract "47-52% zero-adv tasks" statistic into a training-efficiency narrative with a
concrete ceiling, answering the reviewer question "how much better could GRPO be with these
fixes?" without requiring new runs.

**Implementation**: Extend `src/pipeline/within_campaign_advantage_audit.py` (from EXP-146):
```python
# Per cycle, per task: count rollouts with pass > 0 and pass < K
effective_task = (0 < pass_count < K)
grad_util_rate = sum(effective_task) / len(tasks)
effective_steps = total_steps * grad_util_rate
# Oracle bound: linear extrapolation assuming utilization = 1.0
oracle_delta_pp = current_pass1_gain * (1.0 / grad_util_rate)
```
Output: 4-row Table 10 (cycle, all_pass, all_fail, effective%, eff_steps, oracle_pp_gain).
