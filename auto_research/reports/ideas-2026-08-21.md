## Top 3 Relevant Papers

### 1. Cue-GRPO: When Correct Solutions Repeat — arxiv:2608.03467 (August 2026)
**Relevance: HIGH — directly addresses GRPO credit concentration on repeated solution forms**

Identifies that GRPO advantage mass accumulates proportionally to solution-structure frequency within a rollout group. Recurring correct forms (e.g., boilerplate list comprehension) dominate; rare but valid alternatives (recursion, custom comparators) are under-credited. Cue-GRPO applies a partition-conditioned rarity reweighting using deterministic Strategy Cues (structural labels, no auxiliary model needed), combined with positive-credit stabilization and within-group mean restoration.

MERA connection: Qwen3-4B on HumanEval likely generates repeated structural patterns for easy problems (over-represented in advantage mass) while rare-but-correct forms get minimal gradient. The train/test routing accuracy gap (92.68% vs 60.98%) is consistent with the model overfitting to narrow solution patterns. AST-level structural cues (`ast.walk()`, top-level statement sequence) can implement Cue-GRPO's partition without any auxiliary model. New in this project — distinct from G²RPO-A (prompt adaptation) and curriculum (batch reordering).

### 2. FlyRoute: Self-Evolving Agent Profiling — arxiv:2605.22057 (May 2026, rev. July 2026)
**Relevance: HIGH — closest published prior to MERA's router co-evolution loop**

FlyRoute grows agent capability profiles from successful routing traffic via a data flywheel. Key innovation: targeted exploration policy that combines profile uncertainty × BM25 relevance × lexical novelty to prioritize under-profiled agents for plausible queries. Results: zero-shot LLM router 72.57% → 78.04% on enterprise developer-support queries.

MERA connection: MERA's TF-IDF + LogReg router is structurally the closest analog. FlyRoute's targeted exploration principle translates to identifying the "uncertain frontier" (|P_router(large) − 0.5| < 0.1) and forcing both models only on those prompts — a targeted version of SCALING_FORCE_BOTH=1. Camera-ready §2 citation as closest prior for MERA's co-evolving router, with differentiator that MERA co-evolves router + model + skill simultaneously (FlyRoute evolves only the router profile).

### 3. HW-Router: Hardware-Aware Routing — arxiv:2608.14575 (August 2026)
**Relevance: LOW for MERA (serving infrastructure, not task quality routing)**

Routes LLM serving traffic based on real-time hardware signals (queue lengths, KV-cache utilization, TTFT/TPOT history). 3.4–3.9× lower latency vs. CARROT/IRT baselines. Not relevant to MERA's task-quality routing (MERA routes by predicted solution quality, not serving cost), but could be cited as "concurrent infrastructure routing work" in a survey context. Not queued as an experiment.

### EXP-176 — Cue-GRPO Rarity-Aware Credit Redistribution via AST Clustering
**ID:** `exp_2026_08_21_001_cue_grpo_rarity_aware_credit_redistribution_ast_clustering`
**Kind:** `grpo_continual`
**Priority:** 7
**GPU:** Required (~2.5h on A800, DAPO + LoRA, 2 cycles)
**Paper:** arxiv:2608.03467

**Rationale:** Standard GRPO applied to easy HumanEval problems generates rollouts dominated by one or two solution structures (e.g., all K=8 rollouts use list comprehension). These over-represented forms accumulate all the positive advantage mass, while rare but correct alternatives receive near-zero gradient. Cue-GRPO (2608.03467) fixes this by partitioning verify-correct rollouts into structural clusters and applying inverse cluster-size weights to positive advantages, ensuring rare solution forms receive proportionate credit. For MERA, implement via Python `ast.walk()` to extract top-level function-body statement sequence type as the Structure Cue (deterministic, no auxiliary model). Apply to cycles 4–5 continuing from cycle-3 GRPO adapter.

Camera-ready §2 citation as closest published prior for MERA's co-evolving router; differentiator: MERA performs 3-component joint evolution (router + model + skill), FlyRoute evolves only the router profile with a fixed agent model.
