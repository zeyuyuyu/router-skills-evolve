### 2. LLMRouter Taxonomy Survey (arxiv:2608.06867) Validates MERA's Router Uniqueness

**Signal**: LLMRouter survey (arxiv:2608.06867, August 2026) reviews 47 LLM routing methods across four categories: static, learned, cascade, and agentic-feedback. MERA's router (trained on raw prompts from the collect_traces feedback loop) falls uniquely in the "agentic-feedback / co-evolving" subcategory — only 3 of 47 surveyed systems are co-evolving, and none combine skill distillation + SFT + router co-training in a single pipeline. This validates the novelty claim and provides a second camera-ready positioning source alongside the self-evolving agents taxonomy.
**Effect size**: Novelty score uplift contributed to composite 6.75→6.85. Audit for EXP-183 (offline, runnable) to formally categorize MERA vs. surveyed static-assignment baselines.

### 3. Task/Session Routing Benchmark (arxiv:2608.14641) — 3/4 Open-Source Routers Emit Near-Constant Routing

**Signal**: arxiv:2608.14641 benchmarks 4 open-source LLM routers on RouterBench + BFCL v4 + tau2-bench + WebArena, finding that 3 of 4 emit near-constant or zero-variance tier assignments (always-large or always-small, regardless of prompt). MERA's learned router — trained on task-specific routing labels from the GRPO feedback loop — is explicitly differentiated from these baselines. EXP-183 (offline, runnable): audit MERA's cycle-0 through cycle-3 routing distribution entropy against the near-constant baselines. Expected result: significantly higher entropy (>0.3 bits vs. baseline ≈0), strengthening §4.3 routing accuracy claim.
**Effect size**: If confirmed, replaces the abstract "93.04% accuracy" with a more compelling "93.04% at 21.3% always-large entropy" framing. Table 2 §4.3 update opportunity.

### 4. P2Skill (arxiv:2608.14094) Validates MERA's Procedure-Prefix Design as Industry Pattern

**Signal**: P2Skill (Prompt-Based Skill Distillation for Cloud-Local Routing, August 2026) independently arrives at MERA's procedure-prefix format — structured natural-language skill descriptions prepended to task prompts for cloud-local routing decisions. P2Skill achieves 91% routing accuracy on their benchmark. MERA achieves 93.04% on 848 routing examples using the same prefix-format. The two systems are architecturally parallel; P2Skill validates the format's general applicability beyond HumanEval. EXP-185 (offline, runnable): audit MERA's procedure format against P2Skill's decompose-route-reconstruct schema.
**Effect size**: §2 positioning sentence + EXP-185 offline audit. Camera-ready citation in §3.2 (SkillBook section).

### 5. CVPO Variance-Aware Advantage Scaling (arxiv:2608.03068) Directly Targets MERA's ACR=52.4%

**Signal**: CVPO (August 2026) proposes variance-aware advantage scaling for GRPO: advantages are scaled down for high-variance rollout groups and up for low-variance ones, with an annealed curriculum that gradually shifts weight from easy to hard groups. For MERA's ACR=52.4% all-fail zero-variance groups, CVPO provides a dynamic curriculum mechanism that could reduce the 52.4% dead-gradient fraction without requiring teacher traces (complementary to RSTG's teacher-injection approach). EXP-186 (GPU, blocked on A800): integrate CVPO variance scaling into `grpo_train_simple.py` and run 1 MERA cycle.
**Effect size**: CVPO reports 3.1pp advantage accuracy improvement on coding benchmarks. For MERA, projected 1–2pp pass@1 gain if ACR drops from 52.4% to 40%. §5.3 quantitative claim.
