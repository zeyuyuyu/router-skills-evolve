## Top 3 Relevant Papers Found Today

### 1. arxiv:2606.09932 — "When RL Fails after SFT: Rejuvenating Model Plasticity for Robust SFT-to-RL Handoff"

**Relevance: ★★★ — HIGHEST PRIORITY TODAY**

**Key finding**: Heavy SFT training reduces model plasticity — the model's ability to accept new gradient updates from RL. Overtrained SFT creates a flat loss landscape near the SFT optimum; RL (GRPO) gradient steps are absorbed by this flat region, leaving effective learning rate near zero, causing RL to fail silently.

**Fix**: A brief entropy-regularized warmup phase at the START of RL training (entropy_coeff=0.05 for first 50 steps, linear decay to 0) injects output distribution noise sufficient to perturb the model out of the flat SFT optimum. In experiments across Qwen2.5-Coder 1.5B/7B on HumanEval + MBPP, this restores RL performance to the level achievable from epoch-1 SFT checkpoint, without discarding epoch-2 learning.

**Direct application**: Our cycle-1 SFT epoch-2 overfitting (EXP-136 finding: loss 0.166→0.271) reduces plasticity exactly as described. EXP-137 fixes this by selecting epoch-1 checkpoint. EXP-138 tests the orthogonal fix: keep epoch-2 checkpoint, add entropy warmup before GRPO-1.

**Paper impact**: §5.4 Hypothesis F gains a second fix path. A 2×2 table comparing epoch-1 vs epoch-2 SFT init × with/without entropy warmup creates a clean ablation for the AAAI submission:

| SFT Init | Entropy Warmup | Expected Skills Arm |
|---|---|---|
| epoch-2 (baseline) | none | 65.85% (cycle-1 dip) |
| epoch-1 (EXP-137) | none | ≥70.73% (predicted) |
| epoch-2 (EXP-138) | yes, 50 steps | ≥70.73% (predicted) |
| epoch-1 (combined) | yes | ≥70.73% (predicted) |

### 2. arxiv:2607.08255 — "Compete Then Collaborate: Frontier AI Teachers Build a Verifiable Curriculum to Improve a Coding Student Beyond Imitation"

**Relevance: ★★★ — HIGH PRIORITY (routing + GRPO curriculum)**

**Key finding**: Multiple frontier teacher models "compete" on a shared task set. Problems where teachers DISAGREE (one passes, another fails) represent the "Goldilocks" difficulty band — informative to the student and verifiably solvable. Training the student via GRPO (not SFT) on ONLY these disagreement problems achieves +49% relative improvement (5.9% → 8.8% pass@1) on competition benchmarks.

**Direct application**: Our pipeline already runs both large model (GPT-5.5) and small model (Qwen2.5-1.5B) on every task (SCALING_FORCE_BOTH=1). The "disagreement zone" is already captured in traces.jsonl as tasks where `large_pass=True, small_pass=False`. This is precisely the routing-critical difficulty band. Using this as the GRPO curriculum:
1. Increases ACR fraction (all training tasks are "borderline" → student has genuine room to improve → more non-zero-advantage groups)
2. Complements EXP-135 (no-std-norm): filtering curriculum reduces all-pass groups; std-norm fix handles the remaining degenerate groups

**Paper impact**: Adds a "curriculum" ablation row to Table 9. Grounds curriculum GRPO in the latest frontier-teacher literature. A natural extension: if EXP-139 improves skills arm, future cycles could use a 3-arm curriculum (easy/borderline/hard) following the paper's staircase structure.

### 3. arxiv:2607.22465 — "TRACE-ROUTER: Task-Consistent and Adaptive Online Routing for Agentic AI"

**Relevance: ★★ — FUTURE CONSIDERATION (router evolution)**

TRACE-ROUTER pins all LLM calls for a given task to one backend (selected at admission via contextual bandit), and updates the routing policy using the TERMINAL task reward (pass@1 at the end of the trajectory). This is contrasted with our approach: offline router retraining at the end of each cycle, using the previous cycle's trace outcomes as training signal.

**Key insight**: offline routing has a 1-cycle delay between outcome and router update. TRACE-ROUTER's online approach closes this loop within the same trajectory. For our pipeline, this would mean updating the router after each GRPO rollout (using the rollout's final pass@1 as the reward signal) rather than waiting for the next offline retraining cycle.

**Action**: Not queued today (already at 2-experiment cap, and this requires more pipeline modification than EXP-138/139). Record for post-AAAI consideration. If EXP-138/139 provide marginal gains but routing accuracy plateaus, TRACE-ROUTER-style online routing could be the next major improvement axis.

    traces = [t for t in traces if t.get('large_pass') and not t.get('small_pass')]

**Expected mechanism**: Borderline-only curriculum reduces all-pass ACR groups → std(group rewards) consistently > 0 → richer GRPO gradient signal. Complementary to EXP-135 (no-std-norm), which fixes the advantage formula for degenerate groups; EXP-139 reduces the occurrence of degenerate groups at the input level.
