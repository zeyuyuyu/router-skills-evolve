## Top 3 Relevant Papers

### 1. arxiv:2609.18779 — CERA-MoA: Co-Evolving Routing Mechanisms with Continually Learning LLM Agents (Sep 16, 2026) ⚠️ CRITICAL

**Authors**: Jiaxuan Jiang, Liyuan He, Zhixuan Fang

**Core idea**: CERA-MoA introduces an iterative RL framework where a dynamic router and independent agent policies co-evolve. A predictive familiarity estimator uses mid-layer hidden states to evaluate semantic competence among agents, avoiding full-rollout overhead. A cumulative-threshold adaptive routing mechanism activates a tailored minimal agent subset per query. Agents are fine-tuned with continual RL on routed queries; the router is updated each cycle to reflect the new capability distribution. Evaluated across multiple domains, outperforms static-agent routing and fixed-workflow fine-tuning baselines.

**MERA intersection**: This is the most critical new paper for MERA's ICLR 2027 submission. CERA-MoA and MERA share the same macro-paradigm: a co-evolving (router, model policy) system that iterates through training cycles. A reviewer who finds CERA-MoA during review and does not see it in MERA's §2 could raise a novelty rejection. Key differentiators:

- **Agent pool**: CERA-MoA uses N homogeneous agents of similar scale (MoA pattern); MERA uses a heterogeneous two-arm design (cheap local Qwen3-4B + frontier GPT-5.5), explicitly exploiting the capability gap for cost-efficient routing.
- **Routing signal**: CERA-MoA routes via mid-layer hidden-state familiarity (runtime forward-pass overhead); MERA routes via logistic regression on raw prompt text features (zero runtime overhead).
- **Skill distillation**: CERA-MoA has no skill distillation — agents learn only from RL rollouts. MERA's SkillBook extracts a written solving procedure from teacher traces and prepends it to every prompt, giving the small model a structural scaffold unreachable by self-play.
- **Knowledge source**: CERA-MoA is fully on-policy (agents teach themselves via RL). MERA obtains frontier teacher traces (SFT on GPT-5.5 solutions) — a qualitatively richer signal.

The concurrent-work framing ("also explores co-evolutionary routing; MERA differs in...") positions both papers as complementary rather than duplicative.

**Paper impact**: §2 differentiation sentence + bib entry `cera2026` + possible §1 intro softening. Soundness 0; novelty defense essential; ICLR rejection risk high if absent.

### 2. arxiv:2609.16604 — ExecuCritic: Calibrated Critic Shaping for Code Generation with Verifiable Rewards (Sep 2026)

**Authors**: Liu et al.

**Core idea**: ExecuCritic adds a joint critic to GRPO for code generation. Binary pass/fail rewards reduce each rollout to a single bit, creating a hard credit assignment problem — the policy can't tell which part of a wrong program caused the failure. ExecuCritic trains the critic on the same execution rollouts; the critic predicts pass/fail and generates short diagnostic feedback (which test case fails, why). The coder uses the critic's guidance only when the critic agrees with the executor (calibrated usage, avoiding noisy guidance). Improves over GRPO, prompted reviewer systems, and scalar reward models on 8 code benchmarks, with fewer gradient steps and fewer sandbox executions.

**MERA intersection**: ExecuCritic directly addresses MERA's documented 52.4% ACR (all-fail zero-variance group rate). In MERA's GRPO Phase 3b, prompts where all G=8 rollouts fail contribute zero gradient — the policy sees no useful signal on the hardest tasks. ExecuCritic's joint critic would provide diagnostic feedback on these hard-fail groups, enabling gradient flow even when execution always fails. This is a complementary remedy alongside CVPO (EXP-186, variance-aware advantage scaling) and Dr.GRPO (EXP-120, masked zero-variance groups). ExecuCritic is the most recent (Sep 2026) entry in the execution-feedback GRPO cluster, filling the "critic-based credit assignment" niche not currently in MERA's §2c.

**Paper impact**: §2c RL for Code — 1 sentence noting ExecuCritic as the critic-based credit assignment approach; §3 — 1 future-work sentence on ACR remediation. Add bib entry `execucritic2026`.
