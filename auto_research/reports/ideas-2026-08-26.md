## Top 3 Relevant Papers

### 1. arxiv:2607.17247 — "Distilled Reinforcement Learning for LLM Post-training"

**Key finding:** Distilled RL integrates teacher (large model) supervision directly into the RL objective as fine-grained guidance, rather than using teacher logits in a separate KL term. The key mechanism is **negative sample reset**: for rollouts where the student fails, the teacher's correct solution replaces the student's trajectory, providing a dense credit signal where GRPO alone would produce zero advantage (all-fail groups). Empirically, Distilled RL outperforms both pure GRPO and pure on-policy distillation (OPD) across reasoning benchmarks.

**Relevance to MERA:** MERA's two-phase design (Phase 1: SFT on teacher traces → Phase 3b: GRPO) is an instance of Distilled RL's teacher-guided RL paradigm. Specifically: (a) MERA's SFT provides the teacher-initialized starting point that Distilled RL's theory predicts should reduce the credit-sparsity bootstrap problem; (b) MERA's SCALING_FORCE_BOTH=1 oracle (running GPT-5.5 on every task) is precisely the teacher corpus Distilled RL uses for negative sample reset. An offline audit mapping MERA's pipeline onto the Distilled RL framework provides a clean camera-ready §5.1 citation: "MERA's SFT→GRPO sequence instantiates Distilled RL [arxiv:2607.17247], providing teacher-initialized parameters that reduce GRPO's credit-bootstrap cost in the dark room." → **EXP-192**

### 2. arxiv:2608.03467 — "When Correct Solutions Repeat: Rarity-Aware Credit Redistribution for GRPO" (Cue-GRPO)

**Key finding:** In GRPO, when multiple rollouts in a group all succeed (the "bright room" symmetric counterpart to the dark room), they accumulate equal positive credit mass regardless of solution diversity — uniform advantages provide no discriminative signal for learning. Cue-GRPO partitions correct responses into clusters using deterministic strategy cues, then redistributes positive advantages proportional to cluster *rarity* (rare solution strategies receive higher credit). Improvement is largest at high sampling budgets, suggesting rarity-aware redistribution is most beneficial when rollout diversity is high.

**Relevance to MERA:** MERA's dark room analysis (§5.3/5.4) currently focuses on the all-fail case (ACR=52.4%). Cue-GRPO provides the symmetric bright-room framing: on the ~48% of HumanEval tasks where MERA's small model produces at least one correct rollout, many may be all-success groups (every K rollout passes) → uniform advantages → zero gradient. An offline audit using MERA's existing cycle-1/3 rollout logs estimates what fraction of rollout groups are all-success, and computes the implied gradient mass lost to bright-room collapse. Camera-ready §5.4: "MERA's use of K=4 rollouts with temperature=1.0 provides diversity that mitigates bright-room collapse [arxiv:2608.03467]." → **EXP-193**

### 3. arxiv:2608.01804 — "LEAP: Lean Environment-Feedback via Adaptive Pruning for Code RL in GPU Kernel Generation"

**Key finding:** LEAP introduces Difficulty-Conditioned Pruning (DCP), a dynamic gating mechanism that prunes both trivially-easy tasks (all rollouts pass → zero advantage) and catastrophically-hard tasks (all rollouts fail → zero advantage), reserving GRPO compute for tasks in the productive difficulty band. Rank-Based Reward replaces binary pass/fail with pairwise tournament outcomes within groups.
