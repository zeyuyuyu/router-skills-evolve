## Top 3 Relevant Papers Found Today

### 1. arxiv:2608.03223 — "Agentic Reinforcement Learning with Self-Distilled Reward Shaping"

**Relevance: ★★★ — DIRECT CONCURRENT SYSTEM — MUST CITE BEFORE AUG 15**

**Key finding** (August 4, 2026): ADRS proposes training-only privileged skills for multi-turn code agents. The core insight: sparse trajectory-level rewards fail to identify which intermediate decisions caused success/failure. ADRS resolves this by using a frozen policy snapshot conditioned on task-matched procedural skills to rescore tokens from skill-free trajectories, constructing a Teacher Value Advantage (TVA) gate. These skills are ONLY available at training time — the inference policy runs without any skill conditioning, avoiding distribution shift. Results: consistent improvement on long-horizon interactive benchmarks across GRPO, PPO backbones, reduced-data settings, and unseen tasks.

**MERA vs. ADRS — key differentiators:**

| Dimension | MERA | ADRS (arxiv:2608.03223) |
|---|---|---|
| Skill prefix at inference | **Yes** (procedure prepended to prompt) | **No** (training-only, inference is skill-free) |
| Skill prefix at training | Yes (SFT/GRPO examples include procedure) | Yes (TVA credit-assignment gate) |
| Purpose of skill prefix | Task-solving guidance | Token-level credit assignment |
| Credit mechanism | Sequence-level GRPO binary reward | Token-level TVA gate (dense) |
| Routing component | **Yes** (explicit logistic regression, Phase 4) | **No** |
| Task horizon | Single-turn code generation (HumanEval) | Multi-turn interactive agents (3-7 steps) |
| Training paradigm | Phased: SFT→GRPO→Router per cycle | Unified RL (GRPO/PPO + TVA) |
| Co-evolution across cycles | **Yes** (LLM + SkillBook + Router) | No (single-run RL training) |

**Why the design inversion is defensible for MERA**: MERA uses inference-time procedure prefix in single-turn code generation where distribution shift (the policy becoming dependent on privileged info) is minimal — the prompt is self-contained and each task is independent. From cycle 1, MERA's procedure effectively collapses (EXP-163 finding: 118–129 chars, no code, no rubric structure), so the inference-time prefix adds negligible information. At cycle 0, the GPT-5.5 procedure (1102 chars) acts as a teacher demonstration, comparable to ADRS's privileged skill signal.

**Paper additions needed by Aug 15**:
- **§2 Concurrent Work** (new paragraph): "ADRS (arxiv:2608.03223, concurrent) trains multi-turn code agents with training-only privileged skills as a credit-assignment signal (Teacher Value Advantage gate), explicitly avoiding inference-time skill conditioning to prevent distribution shift. MERA differs in three respects: (1) MERA uses the SkillBook procedure at inference time in single-turn code generation, where distribution shift risk is lower; (2) MERA maintains an explicit router trained on labeled traces rather than folding routing into the RL reward; (3) MERA co-evolves the LLM, SkillBook, and router across N cycles — ADRS is a single-run RL training framework without multi-component evolution."

### 2. arxiv:2606.22317 — "Curriculum Reinforcement Learning Can Incentivize Reasoning Capacity in LLMs Beyond the Base Model"

**Relevance: ★★ — THEORETICAL GROUNDING FOR DAPO IMPLICIT CURRICULUM + STAIRCASE GRPO**

**Key finding** (June 2026): Curriculum RL — ordering tasks easy-to-hard — enables models to exceed their base model ceiling on reasoning tasks. Mechanism: easy tasks bootstrap success rate, allowing GRPO to receive non-zero gradient; progressively harder tasks push the policy into regions unreachable from random initialization. Empirically: +8.3pp on MATH-500 over non-curriculum GRPO. Formally: shows that tasks at the capability frontier (medium difficulty, 20–70% pass rate) carry the highest gradient signal; easy/hard tasks contribute near-zero gradient (consistent with RFT zero-variance theory, arxiv:2507.05386).

**Connection to MERA**:
1. **Phase 3b DAPO**: MERA's DAPO dynamic sampling filters out all-pass and all-fail groups — equivalent to selecting curriculum-frontier tasks (20-70% success rate). arxiv:2606.22317 explains WHY this helps: these frontier tasks maximize gradient signal toward exceeding the base model. MERA's ACR (Active Curriculum Rate = fraction of non-trivial groups) per cycle: 51.2% (c0), 47.6% (c1), 46.3% (c2), 52.4% (c3). The dip in c1/c2 ACR corresponds to harder residual tasks entering the GRPO batch before the model has capacity to solve them.

2. **Staircase GRPO design** (EXP-099, blocked): Each MERA cycle k applies GRPO on tasks cycle k-1 still fails, progressively increasing difficulty — exactly the curriculum ordering arxiv:2606.22317 formalizes. The paper's theory predicts MERA should exceed the base model ceiling (70.73%) given sufficient cycles — confirmed: cycle 3 = 75.61%.

**Paper additions**:
- **§3 Phase 3b footnote**: "DAPO dynamic sampling implicitly implements curriculum RL by filtering trivially-solved and trivially-failed groups; arxiv:2606.22317 formally shows such curriculum-frontier selection maximizes gradient toward exceeding the base model ceiling."
- **§8 Future Work** (staircase paragraph): "Explicit cross-cycle curriculum scheduling (EXP-099 staircase GRPO, GPU-blocked) would test whether arxiv:2606.22317's curriculum ordering theory, applied across N MERA cycles, can push the small model's HumanEval ceiling further than the implicit DAPO curriculum alone."
